# RUA

RUA is a bilingual Slovenian and English website for occupational therapy services in Ljubljana and the surrounding area. It presents therapy for children, adolescents, and older adults, along with treatment approaches, pricing, practitioner information, and a contact form.

The site represents Tina Zadravec, a qualified occupational therapist and art therapist who provides therapy in clients' homes.

The website is available at [ruaterapija.si](https://ruaterapija.si).
